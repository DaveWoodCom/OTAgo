# Change Log

* **Version 1.1.1 (unreleased)**: Simple Auth token files belonging to users removed from `$users` are now deleted - immediately when such a token is presented, and during housekeeping on the next password sign-in - instead of lingering until they age out.
* **Version 1.1.1 (unreleased)**: Simple Auth now also reads Basic credentials from `HTTP_AUTHORIZATION` / `REDIRECT_HTTP_AUTHORIZATION` when `PHP_AUTH_USER` isn't set, so php-fpm/CGI setups that forward the header via `SetEnvIf` or `RewriteRule` work without a shim.
* **Version 1.1.1 (unreleased)**: `$baseURL` detection no longer depends on the Apache-only `REQUEST_SCHEME`; it also checks `HTTPS` and `SERVER_PORT`, so nginx/php-fpm and PHP's built-in server no longer produce a scheme-less `://host/` install link. New `$trustProxyHeaders` option (default `false`) honours `X-Forwarded-Proto`/`X-Forwarded-Host` behind a TLS-terminating proxy. `$baseURL` is now resolved after `configuration.php` loads, so an override there still wins.
* **Version 1.1.1 (unreleased)**: OTAgo now requires **PHP 8.1 or newer** (PHP 7 reached end of life in November 2022). Older interpreters get a clear "requires PHP 8.1" error instead of a parse error. The bundled auth providers declare `requestAuthentication(): never`; custom providers should do the same. A `composer.json` is included for the development tooling (PHPUnit) - there are still no runtime dependencies.
* **Version 1.1.1 (unreleased)**: **Security fix** - Simple Auth accepted any request that supplied an
  unknown username (`?u=<anything>`) with no `Authorization` header or an empty password, because the
  loose `==` comparison evaluated `NULL == NULL`. `isValidUser()` now requires the username to exist and
  compares passwords with `hash_equals()`, which is byte-exact and timing-safe. Anyone running Simple Auth
  should update; treat any build distributed by an affected install as having been publicly downloadable.
* **1.1.1 (unreleased)**: Simple Auth's token-directory housekeeping (`cleanTempDir()`) no longer runs on every request. It is now triggered by a successful password sign-in, and the scan is scoped to OTAgo's own `<prefix>_*.<extension>` token files instead of enumerating the whole directory - so the token-only requests the iOS installer makes don't pay for a directory scan. An unreadable token directory is now a quiet no-op rather than a fatal error. Token expiry is unaffected: the lifetime is still enforced every time a token is used, and expired files are still deleted on sight.
* **1.1.1 (unreleased)**: Simple Auth hardening - `randomUUID()` now uses `random_bytes()` as its only source and throws if no CSPRNG is available, instead of silently degrading to an empty (identical for every user) token. Removing a user from `$users` also revokes their outstanding `?u=&t=` tokens on the next request rather than up to `$simpleAuthTokenLifetime` later; this was already the behaviour and is now covered by tests.
* **1.1.1 (unreleased)**: `ipa.php` and `apk.php` now stream the build in chunks with `Content-Type`, `Content-Length`, `Content-Disposition` and `Accept-Ranges: bytes`, and honour a single-range `Range:` request with a `206` (or a `416` when it can't be satisfied). Downloads show real progress, an interrupted install resumes where it left off instead of starting over, and a large build no longer has to fit in PHP's `memory_limit`. A missing or unreadable file is a plain `404` rather than an empty `200`.
* **1.1.1 (unreleased)**: Android downloads are now served by a new authenticated `apk.php` (matching `ipa.php`), so the `.apk` no longer has to sit in a publicly accessible folder behind a permanent, shareable URL.
* **Unreleased**: Renamed `$installURLPlacehHolder` / `$ipaURLPlacehHolder` to `$installURLPlaceholder` / `$ipaURLPlaceholder` (typo fix). The old names still work but emit a deprecation notice; update your `configuration.php`.
* **Version 1.1.0**: *(2021/09/04)* - Added support for Android
* **Version 1.0.0**: *(2020/01/26)* - Initial Release
